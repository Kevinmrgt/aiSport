## Défaut détecté puis corrigé

Le premier build API a réellement échoué avec
`ERR_PNPM_LOCKFILE_CONFIG_MISMATCH` : l'image utilisait pnpm 9 tandis que les
overrides étaient définis dans `pnpm-workspace.yaml` selon la configuration
pnpm 11 locale. Le dépôt, les images et la future CI ont été alignés sur pnpm
11.9.0, puis les builds ont été entièrement rejoués.

## Commandes réellement exécutées

```powershell
docker build --file apps/api/Dockerfile --tag alcide-api:bloc2-local .
docker build --file apps/web/Dockerfile --build-arg NEXT_PUBLIC_API_URL=http://localhost:3001 --tag alcide-web:bloc2-local .
docker compose --profile tools run --rm migrate
docker compose --profile tools run --rm seed
```

Les deux images ont ensuite été démarrées sur le réseau Docker local, sur les
ports temporaires 3101 et 3100, puis arrêtées après les sondes.
