# C4.2.1 — Modèle de ticket d'anomalie GitHub

> **Statut du document : modèle non renseigné.** Il ne prouve ni qu'une issue a
> été créée, ni qu'une anomalie est réelle. Remplacer uniquement les marqueurs
> `[À compléter]` avec des éléments observables et datés.

Ce modèle reprend tous les champs du formulaire GitHub
[`anomaly_report.yml`](../../../.github/ISSUE_TEMPLATE/anomaly_report.yml). Il
peut être copié dans une issue créée depuis le modèle **Anomalie Bloc 4** ou
conservé ici comme brouillon de preuve C4.2.1.
