# Bundled typefaces

These unmodified font binaries are vendored from the official [Google Fonts repository](https://github.com/google/fonts/tree/6157dfaa640ca5738b4d1a7070fe389c3036d7fc) at immutable revision `6157dfaa640ca5738b4d1a7070fe389c3036d7fc`. No Google Fonts CSS or font download is needed during the Next.js build or at runtime.

Urbanist is the normal variable font (source axis 100–900), registered for the app's existing 400/500/600/700/800/900 weights. Barlow Condensed is bundled as its original normal static 600/700/800/900 fonts. The app retains display: swap and the --font-sans / --font-display CSS variables.

Both families are distributed under the SIL Open Font License 1.1. Original copyright and license notices accompany the fonts in Urbanist-OFL.txt and BarlowCondensed-OFL.txt.

## Restored September display font

The September interface uses Barlow, whose normal static 600/700/800/900 weights are vendored from the official Google Fonts repository (ofl/barlow) and selected in the root layout. Barlow Condensed remains archived here but is not loaded. Barlow-OFL.txt accompanies the restored fonts. No remote font request is made.
